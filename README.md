# iDil tanıtım sürümü

Sınav İngilizcesi uygulaması iDil'in tıklanabilir tanıtımı (uygulama kodu değil). Sorular ve kartlar taslaktır; İngilizce
öğretmeninin incelemesi için yayımlandı. İlerleme yalnız ziyaretçinin tarayıcısında tutulur; sunucuya bir şey gönderilmez.

Sesli telaffuz (`icerik/ses/idil/`) yapay sestir: Kokoro-82M modelinin (Apache-2.0, https://huggingface.co/hexgrad/Kokoro-82M)
iki hazır sesinin karışımıyla önceden üretildi. Gerçek bir kişinin sesi değildir.
